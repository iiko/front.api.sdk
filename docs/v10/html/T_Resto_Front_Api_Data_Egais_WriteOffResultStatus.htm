Member nameValueDescription
Success0The operation completed successfully.
Duplicate1The tare is already unsealed: the unseal record with the same reason exists in the front journal, or the mark is written off according to EgaisMarksInfo (unsealed outside this front group). The second write-off act is not created.
EgaisRejected2The position data is invalid: the mark is not registered in EgaisMarksInfo under the organization of the batch (or belongs to another organization), the iiko product, the alcohol code or the EGAIS product is not found, or the unpacked amount is not set for a keg.
NetworkError3Connection error: the RMS server, UTM or the main cash is unavailable. The operation can be retried later.
UnknownError4Unknown error.
ReasonMismatch5The write-off reason stored in the unseal record of a marked tare differs from the requested one: for a write-off of packed tare the second act is not created, for a cancellation the operation is not possible.
NotCancellable6Cancellation is not possible: the tare is not unsealed in this front group (no unseal record in the front journal under the organization of the batch; for an unpacked marked product the mark is also not written off according to EgaisMarksInfo), or the server does not allow to cancel the write-off document (for example, the act has already been sent to EGAIS).
DuplicateInBatch7The same mark is present in the batch more than once: only the first position with the mark is processed, the repeated positions are refused with this status.
