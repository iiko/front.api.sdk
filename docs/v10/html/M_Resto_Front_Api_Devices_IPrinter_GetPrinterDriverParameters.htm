PrinterDriverParameters GetPrinterDriverParameters()

Return Value

PrinterDriverParameters
Printer geometry and capabilities: line widths for each font, page size, margins, dpi, whether it can print barcode, QR code, logo and image.
Exceptions
ExceptionCondition
DeviceExceptionException to notify that device actions was not successful.
Remarks
Called when the printer is added, set up and started, so the printer may be stopped at the moment of the call: it reports the parameters it knows without a connection or throws DeviceException, which is not treated as an error before the start. iikoFront stores the parameters reported before the start only if it has none for the printer yet; the parameters reported after the start replace the stored ones. Documents are laid out by the stored parameters: a stopped printer with autorun is started before its document is laid out, so the document fits the parameters reported after the start. Until the printer reports its parameters, the defaults are used: 42 characters per line for f0 and f1, 21 for f2, page width of 512 dots. The reported parameters must be valid: line widths and, when set, page width, page height and dpi are positive, margins are not negative. Invalid parameters are rejected and not stored.
