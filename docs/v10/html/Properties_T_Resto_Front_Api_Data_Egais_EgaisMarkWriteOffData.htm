The EgaisMarkWriteOffData type exposes the following members.

Properties
 NameDescription
EgaisAlcCodeAlcohol code of the product in EGAIS. Marked tare: optional, the alcohol code is taken from EgaisMarksInfo and this value is used only when the directory knows the mark without an alcohol code. Unmarked tare: not used, the alcohol code is determined by the product mapping (the unseal record of unmarked tare is stored without an alcohol code, as the front does).
EgaisMarkCodeExcise mark. Empty for unmarked tare. Leading and trailing whitespace is ignored; the mark is compared case-sensitively. If the same mark is present in a batch more than once, only the first position is processed (see DuplicateInBatch).
ProductBarCodeiiko product barcode. Unmarked tare: the product is resolved by it when ProductId is not set (as when scanning in the tare unsealing window). Marked tare: not used.
ProductIdiiko product identifier. Unmarked tare: required unless ProductBarCode is set. Marked tare: not used, the product is determined by the alcohol code of the mark (as in the tare unsealing window).
UnpackedAmountUnsealed (returned) amount in litres. Required for a marked unpacked product (keg: Packed == false in the EGAIS product directory), as in the tare unsealing window; not used for a packed product. Optional for unmarked tare.
WriteOffTypeWrite-off (unsealing) reason. For a cancellation it must be equal to the reason stored in the unseal record (see ReasonMismatch); for unmarked tare the reason is a part of the record identity.
