Parameters

task  PrintTextTask
PrintTextTask with the document to print. Document contains the formatted markup with the doc root. Text lines f0, f1, f2 already fit the line widths reported by GetPrinterDriverParameters; a line may carry the style attributes bold, italic, underline and reverse with the value on. Other elements are passed as is: barcode with the attributes align, heightRatio (a number, the height relative to the default one) and hri (off hides the human readable text); qrcode with the attributes align, size (tiny, small, normal, large) and correction (low, medium, high); logo with the attribute align and the logo number as the value; image with the attributes align and resizeMode and the image in base64 as the value; pulse to open the cash drawer; pagecut to cut the paper. The attribute align takes left, center or right. The doc root may carry the attribute bell with the value true: open the cash drawer when printing. iikoFront appends a trailing pagecut when printable content follows the last cut, so a printed document always ends with a cut.
