EgaisMarkTareOperationCheckResultResult of the preliminary check for one position.
EgaisMarkWriteOffDataData of one position for a write-off or return operation on EGAIS tare. A position is either marked tare (EgaisMarkCode is set; the mark must be registered in the EgaisMarksInfo directory of the front under the organization of the batch, its EGAIS product must be known to the front) or unmarked tare (EgaisMarkCode is empty; the iiko product is identified by ProductId or ProductBarCode and must be mapped to an EGAIS product). The organization (FSRAR id) and the operation time are common for the whole batch and are passed as arguments of the operation. The data and the rules repeat the tare unsealing window of iikoFront, so a tare unsealed through the API can be returned in the window and vice versa.
