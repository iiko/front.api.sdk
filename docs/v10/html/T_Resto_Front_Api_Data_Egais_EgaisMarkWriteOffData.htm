EgaisMarkWriteOffData Class

Data of one position for a write-off or return operation on EGAIS tare. A position is either marked tare (EgaisMarkCode is set; the mark must be registered in the EgaisMarksInfo directory of the front under the organization of the batch, its EGAIS product must be known to the front) or unmarked tare (EgaisMarkCode is empty; the iiko product is identified by ProductId or ProductBarCode and must be mapped to an EGAIS product). The organization (FSRAR id) and the operation time are common for the whole batch and are passed as arguments of the operation. The data and the rules repeat the tare unsealing window of iikoFront, so a tare unsealed through the API can be returned in the window and vice versa.

Marked tare: optional, the alcohol code is taken from EgaisMarksInfo and this value is used only when the directory knows the mark without an alcohol code. Unmarked tare: not used, the alcohol code is determined by the product mapping (the unseal record of unmarked tare is stored without an alcohol code, as the front does).
EgaisMarkCodeExcise mark. Empty for unmarked tare. Leading and trailing whitespace is ignored; the mark is compared case-sensitively. If the same mark is present in a batch more than once, only the first position is processed (see DuplicateInBatch).
ProductBarCodeiiko product barcode. Unmarked tare: the product is resolved by it when ProductId is not set (as when scanning in the tare unsealing window). Marked tare: not used.
ProductIdiiko product identifier. Unmarked tare: required unless ProductBarCode is set. Marked tare: not used, the product is determined by the alcohol code of the mark (as in the tare unsealing window).
